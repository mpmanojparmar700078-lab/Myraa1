# Myra AI Assistant (Android)

Myra is a persistent Android AI assistant layer built with Jetpack Compose, Kotlin Coroutines, Room Database, and the Gemini API.

## Features
- **Local & Cloud Command Parsing**: Instant 0-latency execution for device controls and YouTube integration.
- **Short-Term Conversation Context Tracker**: Remembers active topic entities, pronouns (*"iski"*, *"iska"*), and follow-up actions.
- **Accessibility Service & UI Reader**: Ability to click buttons, navigate apps, and read screen elements safely.
- **Material 3 UI**: Clean edge-to-edge UI with dark/light theme support.
